# 你拼我猜 · 设计语言方向池

> 基座：S3「1管51」。目标：把「机构感」推到大胆且独特。
> 用途：发散池，不追求深度，只追求覆盖广。挑几条组合即可成体系。

---

## 0. 先看清原料：S3 现在有什么

| 维度 | 现状 |
|---|---|
| 世界观 | 车站 / 票务 / 编号 |
| 纸 | 票据米白 `#F2EFE4` + 极淡方格纸底纹 |
| 墨 | 纯黑 + **硬投影**（`4px 4px 0`，无模糊） |
| 三色 | 印章蓝 `#1F4E9C` · 印红 `#D33A2C` · 琥珀 `#C98A0E` |
| 字 | 等宽 mono 主导，中文拆字加字距 |
| 零件 | 虚线撕口 / 条形码 / 印章 / 翻牌 / 转盘 / 编号标签 |
| 形 | **几乎全直角**，唯一的圆是转盘 |
| 语气 | 时刻表、候车、检票口 A6 |

**结论**：风格已经立住，但还很"乖"。下面 95 条，都是把它推向极端的杠杆。

---

## 1. 十个打包好的整体方向

如果想要一整条路线而不是零件，从这里挑：

1. **票务局** — 把车站升级成政府机构：一切都要填表、编号、盖章、归档、留存根。
2. **调度中心** — 实时大屏：等宽数字、状态灯、队列、时刻表，永远在刷新。
3. **打孔卡** — 十张牌 = 十列孔位。拼图就是在卡上打孔，揭晓是读卡。
4. **电报局** — 按字计费、压缩、译码。猜错不叫猜错，叫「译码错误」。
5. **蓝晒工程图** — 深蓝底白线 + 网格 + 标注引线 + 尺寸线 + 公差。
6. **热敏小票** — 全站像一张越拉越长的小票，边缘锯齿，字有缺针。
7. **牛皮档案袋** — 卷宗编号 + 别针 + 折角 + 手写批注。
8. **双色套印** — 只用两个专色，故意错位 1px，像廉价印刷品的粗粝感。
9. **机械计数器** — 一切都是滚轮、翻牌、齿轮，数字永远在翻动。
10. **刮刮乐** — 十张牌是刮开区，揭晓是把涂层刮掉。

## 2. 世界观（把功能包装成机构流程）

11. **猜 = 检票** — 答对盖「验讫」，答错盖「退票」。
12. **出题 = 发货** — 包件、运单、签收人、保价金额。
13. **分享 = 转车** — 你的题要换乘几次才到朋友那儿。
14. **热度 = 客流量** — 这题今天多少人次，做成客流曲线。
15. **排行榜 = 候车厅大屏** — 滚动显示，带轻微刷新闪烁。
16. **每日一题 = 当日车次** — 一天一班，误了等明天。
17. **好友 = 同行旅客** — 通讯录是「同乘记录」。
18. **举报 = 退票窗口** — 走一个正经的窗口流程。
19. **重开 = 改签** — 保留原编号，加一个改签章。
20. **会员 = 商务座** — 有独立候车区（更快的房间）。

---

## 3. 字体与版式

21. **全站等宽** — 连汉字也用 `Noto Sans Mono CJK`，彻底机器感，中文像打印出来的。
22. **送纸孔边** — 页面左右两侧连续的圆孔阵列，像打印机走纸边。
23. **点阵数字** — 计时与编号用 5×7 点阵字，像 LED 显示屏。
24. **编号即标题** — 所有标题前挂黑底白字编号，编号比标题大。
25. **表格线分区** — 取消卡片和留白，一律用 1px 表格线切分。
26. **拆字到极端** — 中文标题逐字拉到 `letter-spacing: .5em`，慢读感。
27. **热敏缺针** — 文字随机缺 1px 竖线，像坏掉的打印头。
28. **大数字小汉字** — 数字极大、说明极小，层级全靠字号反差。
29. **虚线排版** — 不用留白分隔，全部用虚线。
30. **双色错位** — 同一行文字印两遍，红蓝各偏移 1px。
31. **制表符画框** — 用 `┌─┐│└┘` 画框，BBS 感。
32. **竖排编号** — 侧边竖排长编号，像档案脊背。
33. **字距即层级** — 层级不靠粗细，靠字距（越重要越宽）。
34. **整页左对齐到底** — 拒绝居中，一切从左边一条硬线开始。

---

## 4. 色彩与材质

35. **三色铁律** — 米白 + 墨黑 + 一个印章色，永不加第四色。
36. **碳式复写紫** — 第二联是紫色复写副本（分享出去的那份）。
37. **牛皮纸棕** — 档案袋材质，配黑油墨。
38. **蓝晒白线** — 深蓝底、白线，工程图感。
39. **纸龄渐变** — 页面从上到下轻微泛黄，越往下越旧。
40. **荧光笔黄** — 全站唯一的饱和色，只用于划重点。
41. **钢印无色** — 只靠阴影可见的凸印，不占颜色。
42. **油墨不匀** — 印章有斑驳、缺角、重影。
43. **打孔屑** — 角落散落圆形纸屑，可扫走。
44. **折痕阴影** — 纸张中间一道折痕，随滚动加深。
45. **套印不准** — 色块故意错位，边缘露出第三色。
46. **复写重影** — 文字带 0.5px 重影，像复写纸。
47. **褪色** — 已完成的题整体降饱和，像放了很久。

---

## 5. 形状与几何

48. **极端直角** — 全站 0 圆角，把「唯一的圆」留给图腾。
49. **齿孔系统** — 所有分区边界都是邮票齿孔，不是虚线。
50. **虚线宇宙** — 线条的粗细与间距编码层级，不靠颜色。
51. **裁切标记** — 四角有印刷裁切线，像未裁的开版。
52. **编号方块** — 每个区块左上角一个黑底白字编号牌。
53. **唯一的圆** — 转盘是全站唯一的圆形，因此成为品牌图腾。
54. **条形码当纹理** — 条形码不只是信息，是主要装饰。
55. **叠印半透明** — 色块叠加产生第三色。
56. **孔位网格** — 背景是打孔卡的孔位阵列。
57. **票据叠放** — 卡片像一叠错开的纸，有厚度与投影。
58. **装订线** — 顶部一排订书钉或线圈孔。

---

## 6. 组件词汇（这套语言的"零件表"）

59. **票根组件** — 任何卡片都能撕下存根，存根保留编号。
60. **翻牌数字** — 所有数字变化都是翻牌，不只是倒计时。
61. **印章徽章** — 状态、成就、身份，全都是不同印章。
62. **检票口标签** — `A6` 式编号标签贯穿全站，包括按钮。
63. **时刻表列表** — 任何列表都长成时刻表：编号 / 名称 / 说明 / 状态。
64. **转盘选择器** — 选张数、难度、分类，都用转盘。
65. **打孔卡输入** — 输入框是一排孔位，输入即打孔。
66. **队列条** — 「前面还有 N 人」的排队进度。
67. **行李牌** — 分享出去的链接是一张行李牌（带挂绳孔）。
68. **卷宗封面** — 每道题有封面：编号、密级、页数、归档日期。
69. **里程表** — 计数用滚轮，不是数字。
70. **票据打印机** — 任何输入都"打印"出来，带撕纸动作。
71. **印章架** — 设置页是选印章，不同印章不同语气。
72. **窗口牌** — 「3 号窗口」式导航。

---

## 7. 动效

73. **吐纸** — 页面加载像小票从打印机吐出来。
74. **翻牌** — 机械翻页，带阻尼，不是淡入。
75. **盖章** — 落下 + 回弹 + 油墨扩散 0.15s。
76. **打孔** — 交互时打一个孔，**孔留在页面上**。
77. **传送带** — 内容横向滚过，像行李转盘。
78. **角动量** — 转盘有惯性、有摩擦、能甩。
79. **撕纸** — 分隔时纸张被撕开，边缘毛糙。
80. **整页微震** — 盖章瞬间整个页面震一下。
81. **逐行打印** — 文字一行行出现，不是整段淡入。
82. **退格** — 删除时像打字机退格，逐个消失并留墨点。
83. **插文件夹** — 卡片从侧面滑入，像插进档案袋。
84. **盖章排队** — 连续操作时印章依次落下，像盖章流水线。

---

## 8. 交互语法（把物理动作变成操作）

85. **长按 = 盖章确认**
86. **拖拽 = 撕票** — 拖动卡片时沿虚线撕裂。
87. **选中 = 打孔** — 选一个 emoji 就在卡上打一个孔。
88. **提交 = 检票** — 把答案"插进"检票机。
89. **撤销 = 划掉重盖** — 不做橡皮擦，只做划横线。
90. **等待 = 叫号** — 「请 A6 号到 3 号窗口」。
91. **拖转盘 = 选张数**
92. **双击 = 翻面** — 卡片背面是条款与编号。
93. **滑动 = 换乘** — 左右滑切换题目。
94. **捏合 = 缩放票据** — 缩放整张票，不是内容。

---

## 9. 文案语气

95. **公文腔** — 「兹证明该用户已成功拼制谜题一道。」
96. **车站广播** — 「各位旅客请注意，A6 次谜题即将发车。」
97. **表格填空** — 提示语做成字段：「事由：______」
98. **编号代人称** — 不提"你"，只提编号：「1管51 已提交」。
99. **免责小字** — 底部一行像真的免责条款的幽默小字。
100. **电报体** — 省略虚词，用 `STOP` 分隔，按字计费。
101. **票背条款** — 每张票背面有使用条款，可以真的点开读。
102. **窗口句式** — 「本窗口不受理 ___」

## 10. 状态与反馈

103. **纸张状态** — 新=平整 / 进行中=折角 / 完成=盖章 / 过期=泛黄。
104. **孔位进度** — 十个孔，用掉几张打几个孔。
105. **印章等级** — 答对=朱印 / 答错=蓝叉 / 神答案=金印。
106. **永久编号** — 每局生成永久编号，可查、可引用。
107. **折痕累积** — 玩过的题留下折痕，玩得越多纸越皱。
108. **盖章数 = 通关数** — 首页展示一枚盖满的章。

## 11. 跨媒介延展

109. **可打印小票** — 分享出去是一张真的能打印的小票（`@media print`）。
110. **条形码分享码** — 二维码画成条形码样式，扫得出来。
111. **票根 OG 图** — 分享到微信的缩略图就是一张票根。
112. **实体打孔器** — 周边：一枚能打孔的实体章。
113. **年度票据册** — 年底把一年玩过的题装订成册。
114. **票据壁纸** — 用你的编号生成专属票据壁纸。

---

## 12. 如果只记三条

1. **把「唯一的圆」图腾化** —— 全站极致直角，只留转盘是圆的。它就成了品牌符号。
2. **把等宽推到汉字** —— 中文也用等宽字体，机器感会立刻翻倍，且成本极低。
3. **把盖章 / 打孔 / 撕票变成交互语法** —— 三个物理动作直接当操作，比任何图标都直观，且**别处抄不走**。

---

## 13. 三个可能的雷区

- **机关感过重 → 不像游戏**：机构语言好笑是因为有反差，全站一本正经会显得冷。建议保留 10~15% 的"破功"（比如某处突然很随便）。
- **等宽汉字可读性差**：正文别用，只用于标题、编号、数据。
- **直角 + 硬投影在移动端很吵**：小屏建议把硬投影减到 `2px 2px 0`，否则视觉噪音过大。
