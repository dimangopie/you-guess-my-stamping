# 设计语言 v2：「打印店」

> ## ⛔ 本文档记录的方向已撤回
>
> **撤回原因**：v2 引入了「网页官僚」这个**外来体系**（荧光色、Cookie 条、验证码弹窗），
> 它和原来的票务机构感是**两套并行的语言**，不是一套的延伸。
>
> 用户判定：**这是融合，不是扩展。** 已回到 v1「1管51」机构感，改为围绕它做**原生扩展**。
> 见 `docs/06-language-v3.md`。
>
> 本文保留作为设计史存档 —— 其中的**推导方法**仍然有效（从用户约束反推语言），
> 失效的只是**结论**（选了"网页"作为第二个体系）。

> 从 S3「1管51」机构感，升级为 **廉价印刷 × 网页官僚**。
> 实现见 `app/base.css` v2 的文件头 —— 那份才是唯一真相源，本文记录推导过程。

---

## 1. 为什么要换

两条用户侧的约束叠在一起，把 v1 的立足点动摇了：

**① 核心用户是社交/派对游戏玩家。**
派对游戏的美术**不能太精致** —— 精致会拉高社交门槛，玩家不好意思大声笑。Jackbox、Among Us、Gartic Phone 都不精致，这是有意的。
而 S3 是当时 90 条风格里**最精致**的一条。它的风险是一句话：**机构感在说话，emoji 在听话** —— 但 emoji 才是笑话本身。

**② 它是网页游戏，用户是网民。**
这暴露了 v1 的一个系统性盲区：那 90 条风格几乎全是**印刷和实体**的美学（票证、制版、机器、建筑）。而用户每天看的东西，恰恰没被覆盖。

「网页」本身就是一种设计语言，而且它比纸质票证**更轻、更不端着**，正好补上①的那个风险。

---

## 2. 新语言的结构

找到一个能把"纸"和"网"焊在一起的东西：**街角打印店**。

它同时满足四个条件：廉价、是机构、**连着纸和网**、是中国网民的共同记忆。

最关键是第三条推出来的结构：

> **外层 = 打印店的物理世界**（糙纸 / 复印 / 盖章 / 歪招牌）
> **内层 = 柜台那台电脑上的网页**（Cookie / 验证码 / 404 / 弹窗）
>
> 两套语言**套在一起，不是拼起来** —— 因为打印店老板真的在用电脑打开网页给你打印。

这个结构一确立，之前打架的两套语言就统一了：**每个页面都是"一张纸 + 纸下面那台电脑"。**

## 3. 配色规则修订

v1 是「三色铁律：米白 + 墨黑 + 一个印章色，永不加第四色」。v2 加了一族，但加得有理：

| 层 | 用色 | 归属 |
|---|---|---|
| **纸上** | 墨黑 + 印章蓝 `--blue` + 印红 `--red` + 琥珀 `--amber` | **你的**作品、票根、单据 |
| **网上** | 荧光洋红 `--neon` + 青绿 `--neon-2` + 荧光黄 `--neon-3` | **平台的**弹窗、广告、验证码、错误页 |

> **网民的日常就是「安静的页面被荧光弹窗打断」。这个对比本身就是设计。**

它顺带编码了一层关系：**平台是荧光的，你是纸的。**

## 4. 新增零件（base.css 第 14 节「网页层」）

### 廉价化的处理
`.xerox` 复印噪点 · `.misreg[data-mis]` 套色错位 · `.folded` 折角 · `.stamp.crooked` 盖歪的章

### 平台层
`.dim` 遮罩 · `.popup` 弹窗 · `.cookiebar` Cookie 条 · `.captcha` 验证码 · `.terms` 条款滚动区 · `.sysbar` 系统提示条 · `.btn.neon` 荧光按钮

### 网页民俗
`.counter` 访问计数器 · `.badge[data-n]` 红点 · `.printing` 正在打印（进度条常卡 92%）

## 5. 浏览器原生的独门武器

这一层最值钱，因为**只有网页能做**，App 抄不走：

| 手段 | 做什么 |
|---|---|
| **`document.title` 变化** | 页面在后台时标题变成 `(1) 有人猜中了 · 你拼我猜`。**最强的召回，成本为零** |
| **favicon 红点** | 未读时图标上一个红点，和真的一模一样 |
| **自定义右键菜单** | 右键 emoji = 撕下票根 / 盖章 / 复印 |
| **控制台彩蛋** | `console.log` 藏一句话，**只给会按 F12 的人看** |
| **URL 即玩法** | 分享链接携带牌局种子，同一链接永远同一手牌 |
| **离线检测** | `navigator.onLine` 断网时页面变成"票据作废" |

## 6. 从 v1 保留了什么

**全都没丢**，v2 是加在它上面：

- 硬投影、等宽主导、拆字标题
- 票据 / 印章 / 表格 / 编号体系
- **材质规则**：深色 = 屏 / 牌，浅色 = 纸（判据：这东西能拿走吗）
- 每个页面的角色设定（房间=调度单、主页=通行证、作品=归档票根、词库=目录册、广场=公告栏）
- `app/` 下所有页面只写版面、不重定义零件

**变的是调性**：从「档案馆的正式文件」降到「街边打印店出来的一叠单子」。

---

## 7. 一句话

> v1 的机构感方向是对的，但**机构选错了**。
> 对一群网民来说，最有共鸣的机构不是**票务局**，是**互联网平台本身**。

纸质票证是"你爷爷那代的官僚"，Cookie 弹窗和验证码才是"你自己的日常"。
把后者做成游戏更狠，也**更便宜** —— 因为它连美术都不用画，浏览器原生长什么样就长什么样。
