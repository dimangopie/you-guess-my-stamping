# 你拼我猜 · 发现期 01
## 五枚随机种子 → 五套落地页风格

> 双钻石模型 · 第一阶段（Discover 发现）
> 目的：用随机字符串作为**强制发散器**，逼出五个彼此不重复的创意方向，而不是反复微调同一个想法。

---

## 0. 种子

| # | 字符串 | 长度 | 数字（位置） |
|---|---|---|---|
| S1 | `具酒价究明讲桥4是了式上1河从出长` | 17 | 4@8, 1@13 |
| S2 | `凤另皮4朋惊不1鱼比音观什0也极` | 16 | 4@4, **1@8（正中）**, 0@14 |
| S3 | `1管51取门少利队音6马高转具老燕` | 17 | **1@1**, 5@3, 1@4, 6@11 |
| S4 | `谈女满无诉真梅4轻帆雾间3亲5音活此今` | 19 | 4@8, 3@13, 5@15 |
| S5 | `和首给涧独热7具至主4立随面持心` | 16 | **7@7（位置=数值）**, 4@11 |

种子由 `secrets` 模块从常用字池真随机抽取，数字位置随机，未做人工筛选。

### 全局统计（交叉验证用）

- 全串共 85 字，去重 74 字
- **`4` × 4 次、`1` × 4 次**（4 在陈述自己的出现次数）
- **`具` × 3、`音` × 3** —— 汉字里的两个主角：**工具**与**声音**
- `2`、`8`、`9` 从未出现 → 连读 **289 = 17²**（一个完整的正方形）
- 数字最高频位置：**第 8 位（正中）命中 3 次**
- 表达类字符扎堆：`讲`(S1) `谈`(S4) `诉`(S4) `音`(S2/S3/S4) `观`(S2)

> **整体叙事**：85 个随机字自己拼出了一句话——「用某个**工具**，发出一个**声音**，等别人**看见**」。
> 这正好就是本游戏。而数字层给出的是一块**正方形画布**和一条**倒计时**。

## 1. 逐条解构（每条串的独有机关）

### S1 · `具酒价究明讲桥4是了式上1河从出长`
- 分段：`具酒价究明讲桥` / 4 / `是了式上` / 1 / `河从出长`
- **连锁成词**：`究明`（查明）→ `明讲`（把话说明白）→ `讲桥`（说话之桥）
- 首尾「具 … 长」；数字 4 落在第 8 位
- **机关 = 明牌**：`酒` + `价` = 酒馆价目；`明讲` = 不藏着的说法
- **定向**：市井酒馆。木牌、明码标价、朱印、灯笼、长河。

### S2 · `凤另皮4朋惊不1鱼比音观什0也极`
- 分段：`凤另皮` / 4 / `朋惊不` / 1 / `鱼比音观什` / 0 / `也极`
- **机关一 = 4 → 1 → 0 严格递减**，读作一段倒计时
- **机关二 = 数字 1 占据了正中位（第 8 位）**
- 成词：`朋惊`、`惊不`（惊不惊喜）、`比音`（比一比声音）
- **定向**：夜市电玩。霓虹灯管、倒计时、凤凰与锦鲤、扫描线。

### S3 · `1管51取门少利队音6马高转具老燕`
- 分段：`1管51` / `取门少利队音` / 6 / `马高转具老燕`
- **机关一**：开头 `1管51` 天然是一个**编号**
- **机关二**：首字 `1` + 尾字 `燕`(yàn ≈ 言 yán) = **「一言」**
- **机关三**：`马高转` = **旋转木马**
- 其余：`门`(入口) `队`(排队) `利` `音` `老燕`(候鸟要走)
- **定向**：车站与票据。编号、检票口、翻牌时刻表、旋转木马、候鸟。

### S4 · `谈女满无诉真梅4轻帆雾间3亲5音活此今`
- 分段：`谈女满无诉真梅` / 4 / `轻帆雾间` / 3 / `亲` / 5 / `音活此今`
- **机关一**：**正中位（第 10 字）= `帆`**，页面视觉锚点必须给"帆"
- **机关二**：`无诉` = 无人可诉（情绪核心）；`满无诉` = 满肚子话没处说
- 成词：`轻帆`、`帆雾`、`雾间`、`此今`(≈如今)
- 全五条中**最长（19 字）**，语感最接近散文
- **定向**：水墨长卷。宣纸、竖排、大留白、一点梅脂、慢。

### S5 · `和首给涧独热7具至主4立随面持心`
- 分段：`和首给涧独热` / 7 / `具至主` / 4 / `立随面持心`
- **机关一**：**数字 7 恰好落在第 7 位 —— 位置 = 数值**（全五条唯一一次自指）
- **机关二**：`独热` = **one-hot 编码**。只有一个位置是"热"的（1），其余全是"冷"的（0）
  → 这正是猜谜的数学模型：一个正确答案 + 无穷多个 0
- **机关三**：首尾 `和 … 心`，从"和"走到"心"；正中位（第 8 字）= `具`
- 成词：`持心`（守住本心）、`和首`、`独热`
- `主`(房主) 与 `独`(单人) 恰好是这个游戏的两种模式
- **定向**：坐标系与温度。网格、刻度、one-hot 矩阵、心电图脉冲、冷→热轴。

## 3. 用户画像

游戏机制决定了画像。与「你画我猜」的关键差异：

> 画图版笑点来自**手残**，emoji 版笑点来自**脑洞与错位解读**。
> 门槛更低（不用会画画、手机单手可玩），但表达精度更低 → 「神理解」和「离谱答案」才是核心爽点。

### 画像 A · 通勤拼手「小舟」22 岁 · 大学生
- 场景：地铁上、课间，单手竖屏，3 分钟一局
- 动机：即时爽感，拼完就想看别人猜歪
- 痛点：注册、加载、长教程 —— 一个都不能忍
- **需求：打开就是一块空画布，0 学习成本**

### 画像 B · 群里整活王「阿野」27 岁 · 运营
- 场景：丢进微信群／朋友圈，拉同事朋友一起猜
- 动机：制造话题，看朋友出洋相
- 痛点：结果不可分享 = 白玩
- **需求：一局结束自动生成可发群的高光卡片**

### 画像 C · 围观吃瓜「Lina」31 岁 · 设计师
- 场景：只猜不拼，刷别人的题
- 动机：解谜的「啊哈」瞬间，欣赏别人的脑洞
- 痛点：被强制当创作者
- **需求：纯猜模式 / 每日一题**

### 反画像（明确不做）
竞技排位、硬核计时榜、需要美术功底的自由绘制。
这些会把「轻松整活」拖向「压力竞技」，与核心爽点冲突。

### 由此确定的三条产品约束
1. **首屏必须能玩** —— 落地页里就要有一个活着的画布（五套页面都遵守）
2. **一局只发十张牌** —— 玩家不挑 emoji，系统随机发（见 §5 规则修正）
3. **结果必须可截图分享**

## 5. 规则修正（v2）

第一版落地页是按「挑四个 emoji 放进 4×4 格子」做的，**这是错的**。实际规则是：

1. emoji 是**拖进画布**的
2. 画布上的 emoji 可以**放大、缩小、旋转** —— 自由摆放，没有格子
3. 系统每局**随机发十张左右的 emoji**，玩家只能用这些

### 为什么这个改动让产品更好

| | v1（挑四个 · 格子） | v2（发十张 · 自由画布） |
|---|---|---|
| 玩家动作 | 从全量 emoji 里**挑选** | 从给定的十张里**凑** |
| 稀缺性 | 无 | **强** —— 你想要的 🎯 很可能不在手上 |
| 笑点来源 | 选得妙 | **被逼出来的妙** |
| 与「你画我猜」的关系 | 像填字 | 真的在**画**（emoji 变成笔触） |

「只能用手里的牌」是关键：**约束才是创意的来源**。这与画图版「手残」的笑点同源 —— 都是能力受限之后的意外结果。

### 五套页面据此改了什么

- **画布**：4×4 网格 → 自由画布（emoji 绝对定位 + `scale` + `rotate`）。五页共用同一组落点参数，保证看起来「像手工摆的」而不是「像排版」
- **手牌**：新增「十张牌」托盘，各页用各自的语言表达 ——
  S1 木牌 / S2 霓虹卡槽 / S3 旋转木马转盘 / S4 宣纸画笺 / S5 独热向量
- **用掉的牌点亮**：五页共有的状态反馈
- **文案**：清除所有「四个」的措辞；数字条改为 `10 张随机牌` + `3 拖·缩·转`
- **S2 的 4→1→0 倒数保留** —— 那是种子字符串给的**计时器**，与发牌数无关
- **S5 的 one-hot 概念被强化**：十张牌 = 十个编码位，用掉的位变「热」，其余为 0

### 用几张随你（v2.1）

规则里还有一条关键的自由度：**十张牌用几张随你** —— 不是必须用完，也不固定张数。

这条不能靠文案说，得靠**页面自己演出来**。所以 demo 循环里四道题分别用 **3 / 4 / 5 / 6 张**牌：

| 题 | 用牌数 | 拼法 |
|---|---|---|
| 火上浇油 | 3 | 🔥 ⛽ 💧 |
| 海底捞月 | 4 | 🌊 ⬇️ 🥄 🌙 |
| 画蛇添足 | 5 | 🐍 🖌️ ➕ 🦶 👣 |
| 亡羊补牢 | 6 | 🐑 💨 🕳️ 🧱 🔨 🏠 |

看两轮就明白了：**张数是你自己的选择**。落点表扩到 6 个槽位（`LAYOUT[0..5]`），每题取前 `u` 个。

这顺带给了产品一条天然的**难度轴**：

> 用 2 张拼出来 = 难；用 8 张拼出来 = 送分。
> **出题人自己就是难度调节器** —— 不需要额外做一个难度选项。

这条值得记下来：它把「用几张」从一个限制变成了一个**表达工具**。想刁难朋友就少放两张。
