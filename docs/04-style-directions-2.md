# 你拼我猜 · 设计语言风格池 II

> 承接 `02-style-directions.md`（那篇是"改什么零件"，这篇是"整体变成什么风格"）。
> 格式：**流派名 — 它会让这个产品变成什么**。
> 现状：S3「1管51」≈ 瑞士风格 × 粮票 × 铁路时刻表。以下都是从这个基点出发的分叉。

---

## A. 平面设计正典（12）

1. **国际主义 / 瑞士风格** — 严格数学网格 + Helvetica + 非对称排版。房间的玩家列表变成真正的数据表，画布按黄金比分区。
2. **包豪斯** — 只用圆/方/三角 + 红黄蓝。emoji 被抽象成基本几何形，玩家的拼图是一张构成练习。
3. **荷兰风格派 De Stijl** — 蒙德里安网格，红黄蓝+黑白，粗黑分割线。**画布就是那个网格，emoji 只能落格** —— 正好呼应你们原本"格子"的直觉。
4. **俄国构成主义** — 对角线、红黑、巨大数字、摄影拼贴。比分板做成宣传海报，房间号放大到占半屏。
5. **未来主义** — 速度线、文字自由排布、动感。倒计时爆炸式展开，猜测流沿斜线飞入。
6. **达达** — 拼贴、随机、反逻辑。**「随机发十张牌」本身就是达达** —— 把拼贴感做到底，允许元素互相压盖不讲道理。
7. **超现实主义** — 尺度错乱、物件错位。emoji 的比例完全不讲道理（🌙 比 🏠 大十倍）。
8. **波普艺术** — 网点、重复、商业符号、高饱和。作品墙做成网格重复，最佳歪解用爆炸对话框。
9. **欧普艺术 Op Art** — 视错觉、波纹、震动。猜中的瞬间整个画面震一下。
10. **极简主义** — 减到不能再减。猜题页只留 emoji 和一行输入框，其余全删。
11. **后现代 / 孟菲斯** — 故意幼稚、荧光、波点、几何乱拼。**把机构感故意弄坏**，做成"轻松模式"皮肤。
12. **新浪潮 / 瑞士朋克** — 打破网格、大字层叠、故意不齐。揭晓瞬间答案以超大字号打碎版面。

## B. 前卫复古 · 印刷与制版（★ 你最感兴趣的区）

13. **凸版印刷 Letterpress** — 铅字压进纸里的凹痕。所有文字都带压痕，像真被印上去，鼠标经过时"陷下去"。
14. **丝网印刷** — 套色错位、厚墨、网目。印章故意错位半毫米，颜色边缘有毛刺。
15. **石版画 / 平版** — 颗粒感、平涂色块。颜色边界带颗粒，不用纯色。
16. **珂罗版 / 照相凹版** — 深邃暗部、细腻渐变。适合做成"夜间模式"。
17. **油印机 Mimeograph** — 紫色、模糊、边缘渗墨。**分享出去的题是"复印的第二联"** —— 紫色、比原件模糊、有滚筒印。
18. **复写纸** — 第二联永远更淡。别人的作品在广场上永远是复写件，自己点开才是原件。
19. **蓝晒法 Cyanotype** — 普鲁士蓝 + 白线。一个整站反色的"负片模式"。
20. **蓝图 Blueprint** — 深蓝底 + 白线 + 尺寸标注。拼图台显示每个 emoji 的坐标、缩放值、旋转角，像施工图。
21. **传真机** — 热敏、断线、噪点横条。历史存档的老题用这个质感。
22. **点阵打印** — 针式、断续、低分辨率。答案用点阵字打出来，猜中时"打"出来。
23. **电传打字机 / 电报** — 等宽、大写、`STOP` 分隔。系统提示语全部改成电报体。
24. **打孔卡** — 孔位阵列。**十张牌 = 十列孔位，用掉一张就打一个孔**，孔留在页面上。
25. **中文活字排版** — 字模、字盘、拣字。每个 emoji 是一枚字模，从字盘里拣出来放到版上。
26. **木刻版画** — 刀痕、黑白、粗粝。成就印章做成木刻风。
27. **拓片** — 黑底白字、纸纹、凹凸。把玩家的拼图"拓"下来存成作品。
28. **篆刻** — 朱文/白文、边款、故意残缺。成就印章真的分朱文白文两套。
29. **线装书** — 鱼尾、版心、包角、书耳。作品集做成线装册。
30. **月份牌（1930s 上海）** — 擦笔水彩 + 商标 + 日历。每日一题做成一张月份牌。
31. **铅字时代报纸** — 多栏、细分割线、密密麻麻。广场做成一张报纸头版。
32. **凸版名片 / 铜版雕刻** — 极细线条、花体、压凹。永久编号做成雕刻版。

## C. 前卫复古 · 机构与票证（离你们最近）

33. **粮票 / 布票 / 计划票证** — 极简、编号、印章、粗糙纸。**这几乎是 S3 的原型**。可再推：给每张票加"面额"（这张票值几分）。
34. **单位介绍信** — 抬头、正文、骑缝章。邀请朋友进房间 = 开一封介绍信。
35. **档案袋 / 卷宗** — 牛皮纸、编号、别针、线绳。个人作品页的外壳。
36. **图书馆卡片目录** — 抽屉、铜把手、顶部凸起标签。词库页（已在用）。
37. **借书卡** — 日期戳、手写签名。一道题被谁玩过，用打戳的方式记录。
38. **火车时刻表** — 表格、等宽、编号。**已在用**，可推到极致：做成真能折的折页。
39. **登机牌 / 行李牌** — 撕口、条码、三字码。分享链接是一张行李牌。
40. **邮票** — 齿孔、面值、水印、邮戳。**每道题是一枚邮票，作品集就是集邮册。**
41. **邮戳 / 日戳** — 圆形、日期、地名。完成时间用戳的方式盖上去。
42. **钢印 / 压印** — 无色凸起，只靠光影可见。用于正式认证（个人主页已有一枚）。
43. **骑缝章** — 跨页的半个章。**分享出去时章被切成两半，对方手里是另一半** —— 合起来才完整。
44. **火漆印** — 蜡、立体、不规则、带指纹。用于私密作品。
45. **标本标签 / 植物标签** — 手写 + 印刷混排、极小字。词条详情用它。
46. **显微镜载玻片标签** — 白标签、手写、圆角。单个 emoji 的"成分表"。
47. **存包牌 / 号码牌** — 一半挂包上一半自己拿。房间号做成一对。
48. **罚单 / 通知单** — 复写多联、事由栏。举报/退票走这个形式。

## D. 前卫复古 · 技术与机器

49. **太空时代 / 原子时代** — 星爆、飞碟、芥末黄+橘、乐观。把机构感整体换成"未来乐观"。
50. **中期现代 Mid-Century** — 有机形、芥末黄/青/橘、线条插画。一个更轻松的皮肤。
51. **装饰艺术 Art Deco** — 放射线、对称、金箔、几何。成就殿堂用它。
52. **工业控制面板** — 拨杆、指示灯、警示条、铆钉。**拼图台的操作杆（拖/缩/转）就是三个物理拨杆**。
53. **老式收银机 / 计价器** — 机械翻数、咔哒声。得分板。
54. **保险箱 / 金属资产标签** — 冲压数字、铆钉、氧化。永久编号。
55. **军用物资标记** — 喷漆模版字、油桶、批次号。房间号。
56. **集装箱编号** — 校验位、超大字、等宽、四段式。房间号自带"校验感"。
57. **航空运单 AWB** — 多联、条形码、IATA 规则。多联票根。
58. **地铁线路图（Vignelli）** — 45°/90° 折线、站点圆点、颜色编码。**把接力模式画成线路图**：A 拼 → B 猜 → C 猜 是一条线，换乘站就是"猜歪"。
59. **电路图 / 原理图** — 符号、连线、元件标号。作品页做成"拆解图"。
60. **气象图** — 等压线、风向标、符号表。热度可视化。
61. **航海图** — 罗盘玫瑰、水深数字、经纬网。探索广场。
62. **天体星图** — 星等、星座连线、赤经赤纬、观测记录。把作品铺成一片星空。
63. **工程制图** — 标注引线、公差、剖视、剖面线。拼图台显示"这枚缩放 2.5×、旋转 −5°"。
64. **解剖图谱（复古医学）** — 精细线描 + 手写标注 + 编号。把一道题"解剖"成笔触。

## E. 数字原生与亚文化

65. **蒸汽波 Vaporwave** — 粉紫渐变、罗马雕塑、日文、网格地平线。一个"梦境模式"。
66. **Y2K / 千禧未来** — 液态金属、泡泡、透明塑料、像素。与机构感形成极端反差。
67. **酸性设计 Acid Graphics** — 液态铬、镭射、哥特字、拉伸。用于神答案揭晓。
68. **赛博朋克** — 霓虹、密集信息、汉字雨、雨夜。夜间房间。
69. **8-bit / 像素艺术** — 像素网格、有限调色板。一个"复古游戏机"皮肤。
70. **矢量街机** — 发光线条、纯黑底、几何。猜题界面。
71. **硬核朋克传单** — 复印机、剪贴、大小混排、愤怒。词库广场的"野生"区。
72. **锐舞传单（90s）** — 荧光、扭曲字、极密。房间进行中的紧张感。
73. **滑板贴纸** — 高饱和、粗描边。成就做成贴纸，能贴在自己的通行证上。
74. **涂鸦 / TAG** — 喷漆、签名、领地。出题人的签名。
75. **独立杂志 Zine** — 订书机、剪贴、手写、错版。个人作品集。
76. **模拟恐怖 Analog Horror** — VHS 噪点、警告条、紧急广播。倒计时最后 10 秒。
77. **怪核 Weirdcore** — 廉价 3D、超现实、错位文字。**盲拼模式**（看不到画布）。
78. **深炸 Deep-fried** — 过饱和、噪点、镜头光晕。最佳歪解爆红时。
79. **烂画风 / 邪典** — 故意画坏。怪答案的表情包化。
80. **干净核心 / 治愈系** — 柔和、留白、圆润。与粗野形成对照的"轻松版"。

## F. 从非平面借

81. **粗野主义建筑** — 清水混凝土、体量、无装饰。**页面结构裸露**：网格线可见，边框就是结构。
82. **日式代谢派** — 可生长的胶囊单元。房间席位像胶囊一样增删、附着。
83. **苏联现代主义建筑** — 几何、纪念碑性、对称。成就殿堂。
84. **包豪斯舞台 / 机械舞蹈** — 人偶、几何服装。玩家的头像系统。
85. **打字机** — 键杆、色带、压痕、回车铃。输入框用它。
86. **卡片柜** — 抽屉拉出、导轨、铜牌。词库导航。
87. **取号机 / 排队系统** — 号码纸、叫号、窗口。等待状态。
88. **行李转盘 / 传送带** — 流水、循环。广场的无限流。
89. **老式电梯楼层指示** — 指针、楼层数字、叮。进度。
90. **机械翻页牌 Split-flap** — 已在用。可以推到**整个页面骨架都是翻页牌**。

## 组合建议（挑两条相乘，比单用一条更独特）

| 组合 | 得到什么 |
|---|---|
| **瑞士风格 × 粮票** | 数学网格 + 票证质感 —— 现有 S3 的"升级版"，最稳 |
| **达达 × 打孔卡** | 随机拼贴 + 机械孔位 —— **最贴合"随机发十张牌"这个机制** |
| **凸版印刷 × 电报** | 触感 + 机器 —— 最有"真的印出来"的说服力 |
| **蒸汽波 × 档案袋** | 梦境 + 机构 —— 反差最大，最前卫 |
| **地铁线路图 × 接力模式** | 玩法与视觉直接对应 —— 最"聪明"的一条 |
| **模拟恐怖 × 倒计时** | 只用在最后 10 秒 —— 局部用药，风险最低 |

## 三条判断

1. **你们已经在 A 区第 1 条和 C 区第 33、38 条上了。** 想更独特，往下走不如往**横**走 —— 找一个没人拿来做过 UI 的领域（D 区第 58、C 区第 43）。
2. **机制与风格对齐的那几条最值钱。** 达达（随机）、打孔卡（十张牌）、地铁图（接力）、月份牌（每日一题）—— 它们不只是好看，而是**让玩法本身变得可见**。
3. **前卫复古的风险是"博物馆感"。** 复古容易做成"好看但跟我无关"。解法是**留一个当下的出口**：一个现代的无衬线字体、一个真实的交互反馈，让用户知道这是 2025 年做的。
