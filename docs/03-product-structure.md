# 你拼我猜 · 产品结构与页面定义

> 设计语言：S3「1管51」（机构感 · 票务 · 编号 · 等宽 · 硬投影）
> 本文档定义**做什么**；视觉怎么做见 `app/base.css`。

---

## 0. 一句话

**系统发你十张 emoji，拼出一句话，让朋友猜。**

核心循环：**拼 → 发 → 猜 → 揭 →（回看歪解）**

循环里最值钱的不是「猜中」，是**歪解** —— 别人猜错的答案往往比正确答案更好笑。整个产品应该围绕「收集歪解」来设计，而不只是「判定对错」。

---

## 1. 游戏模式

### 1.1 三条主轴（先定关系，再定玩法）

| 轴 | 说明 | 典型场景 |
|---|---|---|
| **单人** | 自己和系统玩 | 通勤、睡前、等人 |
| **同房** | 实时多人，有房间号 | 群聊里开一局 |
| **异步** | 传链接，朋友随时来猜 | 发朋友圈、私聊整活 |

### 1.2 七种玩法

玩法与主轴是**正交**的 —— 同一种玩法可以单人玩，也可以开房玩。

| # | 模式 | 一句话 | 支持的主轴 |
|---|---|---|---|
| 1 | **经典** | 你拼，别人猜 | 全部 |
| 2 | **接力** | 你拼 → A 猜 → A 按自己的答案重拼 → B 猜……最后把首尾两幅画并排看 | 同房 / 异步 |
| 3 | **同题** | 所有人拿到同一组十张牌拼同一个词，然后互相猜 | 同房 |
| 4 | **反向** | 给你答案，你猜别人是怎么拼的（从几个候选画布里选） | 单人 / 同房 |
| 5 | **合作** | 两人共用一块画布：一人只能拖，一人只能缩放旋转 | 同房 |
| 6 | **盲拼** | 拼的时候看不到画布，揭晓那一刻才知道自己拼了什么 | 全部 |
| 7 | **每日** | 一天一题，全球同题，只比用时 | 单人 |

> **接力**和**同题**是社交传播的主力 —— 它们天然会产生「对比图」，而对比图是可截图的。

### 1.3 修饰器（可叠加到任何玩法上）

修饰器是**难度与性格的旋钮**，不是独立模式。

| 修饰器 | 取值 | 作用 |
|---|---|---|
| **牌数** | 2 / 3 / 5 / 10 张 | 主难度轴。2 张 = 地狱，10 张 = 送分 |
| **时限** | 无 / 120s / 60s / 30s | 拼图与猜题各自计时 |
| **禁用操作** | 只能拖 / 不能转 / 不能缩放 | 制造残障式创意 |
| **可见性** | 公开 / 仅链接 / 仅自己 | 影响作品是否进广场 |
| **允许歪解投票** | 开 / 关 | 决定是否评选「最佳歪解」 |

### 1.4 计分

不做硬核排位（与「轻松整活」冲突）。只记三件事：

- **猜中速度** —— 从看到到猜对用了多久
- **被猜中率** —— 你的题被多少人猜中（太低=太偏，太高=太直白，中间最好玩）
- **最佳歪解票数** —— 由所有猜错的人投票产生

## 2. 词库系统

### 2.1 官方词库（分类）

| 分类 | 例子 |
|---|---|
| 成语俗语 | 画蛇添足、对牛弹琴 |
| 日常短语 | 「我先睡了」「在吗」 |
| 影视 | 电影名、剧名、名场面 |
| 歌名歌词 | 歌名、副歌一句 |
| 网络热梗 | 当季流行 |
| 地名城市 | 「重庆」「哈尔滨」 |
| 品牌产品 | 「蜜雪冰城」 |
| 英文单词 | 四级词、日常词 |
| 二次元 | 番名、角色 |
| 经典题库 | 你画我猜的老题 |

每类给 **1~5 星难度**，可单独勾选。

### 2.2 自定义词库

一条词库 = 一个可玩的题目集合。创建方式：

- **手动录入** —— 一行一条
- **粘贴导入** —— 从聊天记录、笔记整段粘贴，自动按行切分
- **文件导入** —— `.txt` / `.csv`
- **从一局存下来** —— 玩到好题，一键存进自己的词库
- **AI 扩写** —— 给几个种子词，自动补到 50 条（可选）

分享范围：**仅自己 / 分享给好友 / 公开到词库广场**。

### 2.3 词库卡片字段

```
┌──────────────────────────┐
│  NO. 1管51        [公开]  │   ← 编号 + 可见性印章
│  《我家的梗》             │   ← 名称
│  32 条 · ★★☆ · 作者 阿野  │   ← 条目数 / 难度 / 作者
│  被玩 1,204 次 · 猜中 43% │   ← 热度 / 平均猜中率
└──────────────────────────┘
```

「猜中率」是词库的关键指标：太低说明词太偏没人玩得下去，太高说明没意思。**40~60% 是甜区。**

## 3. 信息架构

```
/                     落地页（营销：说服）
│
├─ /login             上网登记：登录 / 注册（**进门**）
│
├─ /plaza             广场：今日一题 · 公告流 · 榜单（**发现**内容）
│
├─ /lobby             大厅：选模式 · 加入房间 · 快速开始（**开始玩**）
│
├─ /room/:id          游戏房间（实时调度）
│   └─ /room/:id/compose   拼图台（房间内的编辑态）
│
├─ /guess/:id         猜题页（异步链接落到这里）
│
├─ /banks             词库：官方目录 + 我的 + 词库广场
│   └─ /banks/:id     词库详情
│
├─ /u/:id             个人主页（通行证）
│   └─ /me/works      个人作品（归档票据册）
│       └─ /works/:id 作品详情（含歪解时间线）
│
├─ /settings          设置
│
└─ 错误页（机构里真实存在的「通告」—— 一张纸 + 一枚章 + 办理指引）
    ├─ /404           查无此站 —— 站名被红笔划掉的站台通告
    ├─ /500           设备故障 —— 抢修通告，进度卡在 92%
    ├─ /offline       线路中断 —— 在线时反而显示「线路正常」
    └─ /full          限乘通告 —— 满员，可登记候补
```

**三类页面的分工：**

| 类型 | 页面 | 任务 |
|---|---|---|
| **营销页** | `/` | 说明白 |
| **工具页** | 其余全部 | 用起来快 |
| **错误页** | 404 / 500 / offline / full | **出错时是这套语言最纯的时候** —— 错误页就是机构里真实存在的「通告」：一张纸、一枚章、一个编号、一条办理指引 |

**`/login` 为什么单独存在**：它承担「进门」这个动作，在这套语言里对应**办证处** ——
取号、填申请表、当场照相、防伪核对、盖章发证、归档打孔，全在这一页。

**落地页是唯一的营销页，其余全是工具页。** 两者共用语言但任务不同：落地页要「说明白」，工具页要「用起来快」。

## 4. 逐页内容定义

### 4.1 落地页 `/`

现在的落地页只讲了「怎么拼」，没讲「有什么」。要补四块：

| 区块 | 内容 | 解决什么 |
|---|---|---|
| ① 玩法 | 十张牌 → 拖缩转 → 猜 → 揭 | 一眼看懂怎么玩 |
| ② 模式 | 七种玩法，卡片矩阵，标注单人或多人 | **功能不明确的问题** |
| ③ 词库 | 官方十类 + 自定义 + 词库广场 | 内容丰富度 + 长期留存 |
| ④ 作品与歪解 | 真实作品的票根墙，突出「最佳歪解」 | 社交证明 + 差异化 |

CTA 保持唯一主按钮：「开始拼一题」。

### 4.2 游戏房间 `/room/:id`

房间里同时在发生三件事，版面必须同时容纳：

```
┌─ 房间头 ────────────────────────────────┐
│  房间 NO. 1管51 · 房主 阿野   [经典·同房] │
├─ 左：玩家调度单 ─┬─ 中：当前谜面 ─┬─ 右：猜测流 ─┐
│  ● 阿野    拼图中 │                │  小舟：海底捞月 │
│  ○ 小舟    猜题中 │   [ 画布 ]      │  阿野：水里的月亮 │
│  ○ Lina    已猜中 │                │  Lina：✓ 猜中了   │
│  ○ 访客    离线   │  倒计时 47      │  ─────────────  │
├──────────────────┴────────────────┴────────────────┤
│  得分板：阿野 120 · 小舟 80 · Lina 200               │
└─────────────────────────────────────────────────────┘
```

关键点：
- **玩家状态**必须有「拼图中 / 猜题中 / 已猜中 / 离线」四态
- **猜测流**是房间的心脏，不是聊天的附属品
- **得分板**常驻底部，不弹窗
- 房间设置（模式 / 词库 / 牌数 / 时限）在房间头可改，改完广播

### 4.3 个人主页 `/u/:id`

做成一张**通行证**：

```
┌────────────────────────────────────┐
│  通行证  NO. 1管51        [钢印]    │
│  ┌────┐                            │
│  │印章│  阿野                       │
│  │头像│  出题人 · 加入 2025.04       │
│  └────┘                            │
├────────────────────────────────────┤
│  出题 128 ｜ 被猜中 47% ｜ 猜中 302  │
│  最快 8.2s ｜ 最佳歪解 36            │
├────────────────────────────────────┤
│  印章墙  [朱印×12] [金印×3] [蓝叉×5] │
├────────────────────────────────────┤
│  我的词库 (3)          → 全部        │
│  我的作品 (最近 3 件)   → 全部        │
│  同乘记录 (好友 12)     → 全部        │
└────────────────────────────────────┘
```

- 编号沿用 `1管51` 体系，每个用户一个永久编号
- 「印章墙」是成就系统，不要用奖杯图标，用印章
- 统计只放 5 个数字，多了没人看

### 4.4 个人作品 `/me/works`

做成**装订成册的归档票根**。每件作品 = 一张票根：

```
┌─ NO. 1管5-128 ────────── [公开] ─┐
│  🌊  ⬇️  🥄  🌙                   │  ← emoji 快照（保留大小/角度）
│  海底捞月 · 用了 4 张             │  ← 答案 + 用牌数
│  被猜 63 次 · 猜中 41% · 最佳歪解 ★│
├──────────────────────────────────┤
│  展开 ▸ 猜测时间线                │
│   14:02  小舟  猜「水里的月亮」    │
│   14:05  Lina  ✓ 猜中（用时 8.2s）│
│   14:09  访客  猜「洗澡」    ★歪解 │
└──────────────────────────────────┘
```

- **emoji 快照必须保留原来的大小和角度** —— 那是作品的笔迹，不能重排
- 「最佳歪解」用朱印标出，是整个页面最该被看到的东西
- 操作：重发 / 改答案 / 改可见性 / 删除

### 4.5 词库 `/banks`

做成**目录册 + 索引卡抽屉**：

- 顶部：搜索 + 「新建词库」主按钮
- 官方目录：十类卡片，每张显示条目数与难度星
- 我的词库：卡片列表，带编辑入口
- 词库广场：热门 / 最新两个榜单，卡片带作者与猜中率

---

### 4.6 广场 `/plaza`

做成**公告栏**。它与「大厅 `/lobby`」是两个不同的页面，**别合并**：

| | 广场 `/plaza` | 大厅 `/lobby` |
|---|---|---|
| 回答 | 「有什么好玩的」 | 「我要玩哪个模式」 |
| 内容 | 别人的题、榜单、热门词库 | 模式选择、建房、加入房间 |
| 用户状态 | 闲逛、没目的 | 有明确意图 |
| 数据 | 公共内容流 | 房间列表 |

没有广场，产品就只在「你自己带朋友来」时才成立 —— 这是个社交游戏的生死问题。

版面：

```
┌ 公告栏 NO. 1管51-P · 在展 N 件 · 今日新增 N ─────┐
├─────────────────────────────────────────────────┤
│ 置顶：今日一题（全球同题 · 比用时 · 倒计时换题）  │
├──────────────────────────┬──────────────────────┤
│ 筛选 + 公告流             │ 榜单大屏 × 3          │
│  · 封存态：谜底封存 + 去猜 │  ★ 最佳歪解榜         │
│  · 已揭晓：答案 + 最佳歪解 │  ⚡ 最快猜中           │
│                          │  ◆ 最热出题人         │
├──────────────────────────┴──────────────────────┤
│ 热门词库（索引卡横排）                            │
└─────────────────────────────────────────────────┘
```

三个关键决定：

1. **「最佳歪解榜」放三块榜单的第一位。** 它比「最快猜中」更能代表这个产品 —— 猜中是技巧，猜歪是性格。
2. **公告流分两态混排**：封存的题（能玩）和已揭晓的题（能笑），用印章区分。用户一眼就知道哪些点得动。
3. **置顶只放每日一题，不做轮播。** 一天一件事，符合「车次」隐喻，也不让人分心。

## 6. 视觉系统新增零件（在 S3 基础上）

现有零件：票根 / 虚线撕口 / 条形码 / 印章 / 翻牌 / 转盘 / 编号标签 / 时刻表 / 网格纸 / 硬投影。

| 新零件 | 用在哪 | 形态 |

| **玩家状态灯** | 房间 | 圆点 + 文字，四态四色（拼=琥珀闪、猜=蓝、中=朱、离线=灰） |

## 7. 材质规则：深色用在哪

这是**评审后补的一条硬规则**。之前深色块在这个语言里没有规矩 —— 有时当「屏」用（榜单），有时纯粹拿来**强调**（把「每日一题」公告涂黑），结果同一个组件在不同页面长得不一样。

**规则：深色 = 屏 / 牌。浅色 = 纸。**

| 材质 | 是什么 | 例子 |
|---|---|---|
| **纸**（浅） | 能被拿走、填写、归档的 | 票根 · 单据 · 名单 · 清单 · 公告 · 索引卡 |
| **屏**（深） | 只能原地看、实时或汇总的 | 榜单 · 时刻表 · 记分牌 · 倒计时 |
| **牌**（深） | 标识而非内容 | 导航 · 页脚 |

判据一句话：**这东西能拿走吗？** 能 → 纸；不能 → 屏。

### 两条禁令

1. **深色不是强调手段。** 想强调一张纸，用盖章、朱红竖条、放大编号 —— **不要把纸涂黑**。
   （反例：广场的「每日一题」原本是一条黑底横条。修法：改回纸，靠 8px 朱红竖条 + 放大标题强调，只让**倒计时那一小块**做成深色屏。）
2. **字段多、字号小的列表一律回纸上。** 深底小字可读性会崩。
   （正例：词库的两张榜单有 7 个字段 + 小字号，保持纸面 —— 这恰好标出了规则的边界。）

### 审计与修正记录

| 区块 | 原状 | 判定 | 处理 |
|---|---|---|---|
| nav / footer | 深 | 牌 | 保留 |
| 广场 榜单大屏 ×3 | 深 | 屏 | 保留 |
| 广场 每日一题 | 深 | ✗ 是公告（纸） | **改纸** + 朱红竖条；倒计时单独做深色小块 |
| 落地页 时刻表 | 浅 | ✗ 是屏 | **改深**（S3 原版即深色，此前被误改浅） |
| 房间 玩家调度单 | 浅 | 纸 | 保留 |
| 房间 得分板 | 浅 | ✗ 是屏 | **改深**，并同步调整深底下的列色 |
| 词库 两榜 / 词条清单 | 浅 | 纸 | 保留（字段多、字号小） |

## 8. 明确不做

- 排位赛、段位、赛季（与「轻松整活」冲突）
- 需要美术功底的自由绘制
- 复杂的好友系统（第一期只做「同乘记录」）
- 语音 / 视频

## 9. 文件结构

```
你拼我猜/
├─ index.html            项目入口（导航到原型 / 探索 / 文档）
│
├─ app/                  ← 产品原型（v3「1管51」机构感 + 两条扩展轴）
```

### v3 相对 v1 的增量

**新增页面**：`login.html`（办证处）+ 四个错误页（404 / 500 / offline / full）。
**新增能力**：两条扩展轴 —— 印章体系（轴 3）与物理动作（轴 8）。

> **v2 曾经走过一条弯路**：把「网页官僚」当成第二套体系加进来（荧光色、Cookie 条、验证码弹窗）。
> 那是**融合**，不是扩展 —— 它打破了 v1 的三色铁律。已全部撤回，见 `docs/06-language-v3.md`。
>
> **判断标准只有一句：这东西还是同一套物料吗？**
> 扩展是从已有物料里长出新的（印章本来就在，只是没刻那么多枚；手部动作本来就有，只是没做成交互）。
> 融合是把另一套东西搬进来。前者让语言变厚，后者让语言变糊。

**关键约定**：`app/` 下所有页面**只写自己的版面**，不重定义零件 ——
导航、按钮、纸面、票据、印章、表格、状态灯、快照等一律来自 `base.css`。
这是六个页面能像同一个产品的唯一保障。

### 从落地页到工具页的角色切换

落地页是**唯一**的营销页，其余全是工具页。两者共用语言但任务相反：

| | 落地页 | 工具页 |
|---|---|---|
| 任务 | 说明白 | 用起来快 |
| 密度 | 中（要留白给呼吸） | 高（信息优先） |
| 字号 | 大标题撑场面 | 小字号塞信息 |
| 动效 | 多一点（表演） | 克制（不干扰操作） |
| 主按钮 | 唯一，居中 | 多个，就近 |
