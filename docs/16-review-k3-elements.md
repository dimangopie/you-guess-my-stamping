# K3 定点评审 · 三个指定元素（装订条 / 两处页脚）

用户点名三个元素，要求分析**样式 / 位置 / 功能**并交评委。
评委先纠正了我简报里 **7 处错误**，再给判决。以下逐条记录。

---

## 0. 评委对我简报的 7 处纠错（全部核实成立）

1. **`.bind` 不是 works 独有。** `banks.html:485-486` 也用了，且 banks 抄了同样的
   z-index 补丁（243-244）却**没有** works 的窄屏覆盖（226-228）—— 两个消费者已经分叉。
   > 「你这条判断反了，而且真相比你说的更难看。」
2. **「同一个物件两套偏移」只说对一半。** 孔心 167.96，条心 168.1 —— 差 **0.5px，肉眼不可见**。
   > 「它是维护风险（改宽度就会歪），不是画歪了。别当视觉缺陷打。」
3. **「4px 琥珀是全站最粗的分隔线」是错的。** `base.css:130` 页头自己就是 4px 琥珀，
   `room.html:139` 是第三条；base.css 里 3px 出现 5 次、2.5px 4 次。
   > 「页脚那条 4px 是页头的**镜像**，不是孤例 —— 我反对动它。」
4. **`#A9B4CB` / `#B0BACC` 手写属实，但罪状抓错了。** 深底灰一共**五个**值：
   `#B0BACC`(6.70) / `#A9B4CB`(6.28) / `#A8B2C6`(6.14) / `#8D99B1`(4.57) / `#8A96AF`(4.40)，
   **全部过 AA**。
   > 「所以这不是无障碍问题，是**没人建 `--screen-ink` 这个 token**，同一个角色被手算了四遍。」
5. **`aria-hidden` + 面积大不是问题。** 装饰就该 `aria-hidden`；无障碍树和像素面积无关。
6. **「谁在游戏中会翻页」这个论证用错了地方。** 页脚在文档末尾、不在游戏流程里。
   而且实测前提不准：截图视口是 1440×1000，login 的页脚（858..942）**完整落在首屏内**。
7. **我漏掉的三条，比上面所有条目都狠：**
   - **全站 15 个 `footer.site`，`<a>` 数量 = 0** —— 在给不存在的链接写样式，纯死代码
   - **装订条 26px，却向页面收 34px 过路费**，把整列从 x148 推到 x182
   - **装订条的填充色 = 票根存根的填充色**（都是 `--paper-2`），
     读起来像存根的颜色印漏到册子外面

| ② login 页脚 | **删** |

> 删①之后视觉不会变空：每张票根**已经有**自己的归档孔（`works.html:539` 的
> `<span class="hole punching">`，配合 `base.css:362-363` 那个带 `inset 0 1px 3px` 的真孔）。
> **一记录一孔，数量对、位置对、有深度，早就存在。装订条是同一件事的劣质复制品。**

## 2. 1598px 的问题在哪

**都不是我列的三条。** 长度是对的（装订边本来就该跟册子一样长），
`aria-hidden` 是对的，0.5px 偏移不可见。真正的病：

**(a) 它不随内容变化。** 孔距 26px 取自 `--grid`，记录节距约 406px，两者无关系
→ **61 个孔对 4 张票根**。它不是「读数的记号」，它是墙纸。

**(b) 孔是「盖」不是「透」。** `radial-gradient(circle,var(--paper) …)` 是**不透明实心圆片**
压在带网格的纸上。逐像素查过：8 条页面网格线里 **7 条在孔心被抹掉**
（孔距 26 == `--grid` 26，相位恒定只差 2px）。
真孔应该有深度 —— `.hole` 有 `inset 0 1px 3px`；这个孔连 1px 阴影都没有。
> **它不是孔，是白点，是在有格线的纸上打白漆。**

**(c) 它收 34px 只占 26px**，8px 差价买的是「一个已经看不见的物件的影子」（填充对纸底 1.13:1）。

## 3. 页脚的问题在哪

**不是颜色**（五个灰全过 AA），**不是那条 4px 琥珀**（页头同款），
**也不是「位置依赖内容长度」**（页脚在文档末尾本来就是常态）。

问题是**位置**：它站在页面上最贵的一格 —— 滚动的终点，也就是用户的出口 ——
却只放了一句**已经贴在天花板上的东西**。`.logo` 是 `position:sticky`，
每个滚动位置、每个断点都在。而页脚 **0 个链接**，于是每一页的出口都是死路。

最要命的是 `base.css:555` 那句注释：

> `/* 页脚只有一行：不再重复导航（导航在页头已经有了）*/`

> **作者已经判定「不该重复页头」，然后往里放了一份页头 logo 的副本。
> 这条注释本身就是判据。**

再补一刀：login 的「办证处」**在首屏已经出现两次** ——
`login.html:137` 的 `办 证 处 · 1 管 51 站`，以及申请表抬头的「办证处」。页脚是第三次。

### 删掉之后，三个词去哪

- **「你拼我猜」+「1管51」→ 哪也不去。** 它们已经在 sticky 页头里，永久可见。
- **「办证处」→ login 直接删（137 行已有）；guess 上这是它唯一一次出现，
  所以搬进 eyebrow**：`<span class="lbl-lg">收 发 处 · 猜 题 单 · NO. 1管5-128</span>`
- **腾出来的那一格：什么也别放。**
  > 「login 是表单（出口是提交），guess 是题目（出口是继续猜），主体已经交代完了。
  > **不要用『页脚改成导航』来填**，那是作者 555 行明确否决过的方案。」
- **例外，必须区分**：`index.html:437` 的「已 营 业 N 天」是活数据；
  404/500/offline/full 的那句是页面最后一句台词。
  > 「这几个不是『页脚』，是**结尾**。别把它们和这个品牌牌位当成同一个组件。」

## 4. 共同病根（一句话）

> **三处都在用「当前这一页的像素」回答「这个物件是什么」。**
>
> 长度、偏移、颜色全写死成数字（26 / 13 / 8 / 14 / 18 / 34、`left:189px` 的撕线、
> `#A9B4CB` 一族），于是没有任何一件能在内容变化或换页时自我调整；
> 共享组件只能靠逐页抄补丁维持 —— z-index 两行抄在 works 和 banks，
> 窄屏覆盖只有 works 有，页脚的换行修正只有 index 有。
>
> 顺带一个越界证据：`.ticket::before` 的缺口圆用 `--paper` 填在 `--paper-2` 的存根上，
> 1.13:1 —— 同一类错误：**没人算「这个装饰后面到底是什么颜色」。**

## 5. 可执行改法

**① 删装订条**（零风险，视觉只会变整齐）
```
删 base.css:364-369          .bind / .bind::before / .bind-strip（.hole 保留 362-363）
删 works.html:74-75          z-index 补丁
删 works.html:226-228        窄屏三条
删 works.html:375-376,378    包装 div
删 banks.html:243-244,485-486 同款
保留 works.html:539 每张票根已有的 .hole
```

**若坚持保留装订边**，最小正确版是把它收成一个元素（一个元素 = 一次定位 = 不可能画反）：
```css
.bind-strip{position:absolute;left:8px;top:14px;bottom:14px;width:26px;
  border:1.5px solid var(--ink-4);border-radius:2px;
  background:
    radial-gradient(circle,var(--paper) 0 6px,transparent 6.5px) 50% 3px/13px var(--grid) repeat-y,
    var(--paper-2)}
```
删掉 `.bind::before` 与两页的 z-index 补丁。净减 3 个坐标 + 2 处补丁。

**②③ 零风险批**
```
删 footer.site a / a:hover（全站 0 链接）
:root 加 --screen-ink:#B0BACC（6.70/8.00）、--screen-ink-2:#93A0B8（4.96/5.93）
替换五个手写灰 → 两个 token
```

**要决策批**
```
删 login.html:256-261      整块（首屏 137 行已有）
改 guess.html:116          并入「收发处」，然后删页脚
4px 琥珀                   留着，一个字都别动
其余页的 footer.site       拆成 .signoff（通告尾句）与 .colophon（活数据牌位）
                           这两个是页面内容，不是页脚
```

> **不要做的**：给页脚加导航链接。作者在 555 行已经否决过了，
> 而且那会把「每页出口是死路」换成「每页出口是四个和页头一样的链接」——还是死路，只是更吵。
