# 设计语言 v3：回到「1管51」，然后往外长

> v3 = **v1 物料全量恢复** + **两条原生扩展轴**。
> v2 的「网页层」（荧光、Cookie、验证码、弹窗）已全部移除。
> 实现见 `app/base.css` v3 的文件头 —— 那份才是唯一真相源。

---

## 1. 为什么撤回 v2

### 直接原因
v2 把「网页官僚」当成了第二套体系加进来。但**融合 ≠ 扩展**：

| | 融合（v2 做的） | 扩展（v3 要做的） |
|---|---|---|
| 新元素从哪来 | **外部**引入一套并行的语言 | 从**原有物料**里长出来 |
| 判断标准 | 好不好看 / 有没有梗 | **还是同一套物料吗** |
| 结果 | 两套语言互相稀释，辨识度下降 | 语言变厚，但仍然是它自己 |

v2 引入了荧光色（洋红/青绿/荧光黄），这直接**打破了 v1 的三色铁律** —— 而三色铁律正是这套语言最强的约束。约束一破，"机构感"就散了。

### 但 v2 留下了有价值的东西
v2 逼出来的**真实行为**是好的：分页、滚动解锁、离线检测、右键菜单、限流通知。
这些东西**不是 web 独有的** —— 它们在机构里本来就存在，只是 v2 给它们穿错了外衣。

> **v3 的处理：行为保留，外衣换回机构。**

| v2 的行为 | v3 的外衣 |
|---|---|
| Cookie 同意条 | 一张回执 |
| 验证码 | 防伪核对（比对样张） |
| 平台通知条 | 公告栏 / 通知单 |
| 访问计数器 | 来访登记人次 |
| 进度条 | 「正在复印第 N 号…」+ 细实线 |
| 离线提示 | 线路中断通告 |
| 付费墙 | 「本柜需凭介绍信查阅」 |
| 限流通知 | 驳回通知单 |
| 分页器 | 调阅第 N 卷 |

## 2. 扩展轴 3 · 印章体系

> **印章 = 状态系统。一支产品需要多少种状态，就应该有多少枚章。**

v1 只有一枚"验讫"。印章是这套语言里最富的资源，四维可扩：

### 形状（`.stamp` 的变体）
| 类 | 形状 | 机构里用在哪 |
|---|---|---|
| `.stamp` | 方章 | 通用（最正式） |
| `.stamp.round` | 圆章 | 部门章、资格章 |
| `.stamp.oval` | 椭圆章 | 权限、期限 |
| `.stamp.bar` | 条形章 | 日期、有效期 |
| `.stamp.steel` | 钢印 | 无色的凸起压印，用于"已核验" |
| `.stamp.wax` | 火漆印 | 私密、封缄 |
| `.stamp.half` | 骑缝章 | 半枚 —— 分享时章被切开，两人各持一半 |

### 颜色（功能靠文字，颜色靠修饰）
`.blue` 经办 / `.amber` 进行中 / `.ink` 已注销 · 默认红 = 正式

### 盖印状态
`.crooked` 盖歪 · `.faded` 缺墨 · `.double` 重影

**例**：拼图中=`琥珀·进行`、已猜中=`印红·验讫`、离线=`缺墨`、猜歪=`蓝·存档`。

## 3. 扩展轴 8 · 物理动作即交互

> 机构里真实存在的**手部动作**，直接当交互 —— 比任何图标都直观，而且**别家抄不走**。

这一轴最值钱，因为它**不需要发明新视觉**，只需要把已经存在的动作做出来。

| 零件 | 动作 | 交互表达 |
|---|---|---|
| `.hole` / `.punching` | **打孔** | 孔**永久留在纸上**，是"已用掉"的物理痕迹 |
| `.bind` / `.bind-strip` | **装订** | 侧边一排孔 + 装订条，让一叠纸变成"一册" |
| `.tearline` | **撕线** | 带 ✂ 的虚线，撕开即分离 |
| `.torn-bottom` | **撕口** | 锯齿边，表示"这里被撕走过" |
| `.creased` | **折痕** | 纸张折过的痕迹 |
| `.laminated` | **过塑** | 一层反光膜，表示"正式、不可修改" |
| `.struck` | **划横线** | 注销用红笔划掉，**不做橡皮擦** —— 痕迹本身就是信息 |
| `.label` | **贴标签** | 边角微翘，表示"这是后来贴上去的" |
| `.slot` / `.slot-draw` | **抽签** | 从筒里抽出 —— 对应"系统发十张牌" |
| `.window-sign` | **窗口牌** | 「3 号窗口」式导航 |
| `.queue-no` / `.called` | **叫号** | 号码跳动，轮到你 |
| `.stamping` | **盖章** | 落下 + 回弹 |
| `.flip` | **翻牌** | 数字变化用机械翻页，不用淡入 |
| `.copy2` | **复印** | 第二份更淡，表示"副本" |

### 两个最该先用的
- **抽签**（`.slot`）→ 直接对应「系统随机发十张牌」这个核心机制
- **打孔**（`.hole`）→ 直接对应「用掉几张」，而且孔留在页面上，玩完就是一张战绩

## 4. 没变的东西

v3 完整继承了 v1 的全部规则，一条都没松：

- **三色铁律**：墨黑 + 印章蓝 `#1F4E9C` + 印红 `#D33A2C`（+ 琥珀 `#C98A0E`）。**永不加第四色。**
- **硬投影**：无模糊，2/4/6px 三档
- **材质规则**：深色 = 屏 / 牌，浅色 = 纸。判据：这东西能拿走吗？
- **形态规则**：几乎全直角（最大 3px）。**唯一的圆是转盘与印章。**
- 每个页面的角色设定：房间=调度单 · 主页=通行证 · 作品=归档票根 · 词库=目录册 · 广场=公告栏 · **登录=办证处**

---

## 5. 一条判断

> v2 的失败不是因为"选错了方向"，而是**违反了扩展的定义**。
>
> 扩展是：**从已有物料里长出新的东西**（印章本来就在，只是没刻那么多枚；手部动作本来就有，只是没做成交互）。
> 融合是：**把另一套东西搬进来**（荧光、Cookie、弹窗）。
>
> 前者让语言变厚，后者让语言变糊。
> **判断标准只有一句：这东西还是同一套物料吗？**
