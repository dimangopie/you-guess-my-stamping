# 参考：《破烂艺术家》（Perfect Day Studio）

来源：[手游那点事专访](http://www.nadianshi.com/2026/08/417676) ·
[Steam](https://store.steampowered.com/app/3470550/_/)

**这不是风格参考，这是同类产品的直接竞品** —— 它就是我们这个项目的原型：

> 官宣新作《破烂艺术家》，该作是一款**「你拼我猜」多人联机游戏**……摒弃了常规的
> 手绘、文字出题形式，创新性地以各类**废旧零件、破铜烂铁拼接造型**作为猜题载体

制作人兼主美 KeKe，2024-07 立项，2025-09 首曝，团队核心 3 人。

## 从访谈里拿到的设计原则

1. **素材归纳为 6 种几何形状** —— 素材库有「每形状最低数量」的约束，
   保证随机素材的形状多样性，不会随到单一形状。
2. **颜色**：整体色调统一；塑料更鲜艳明亮，金属更突出**生锈的肌理**。
3. **「旧」和「脏」是语义不是风格**：
   > 而《破烂艺术家》其实就是当下，清晰但是有肌理感，
   > 这种"旧"和"脏"的感觉是因为它们就是**被丢弃的破烂**。
4. **素材包「过时玩具」** —— 千禧年留下的"破烂"。
5. **移动 / 缩放 / 翻转都是「比划」的一部分**：
   > 最早想模拟的就是现实里你面前有一堆东西，拼拼凑凑摆弄和别人比划让人猜的感觉。
6. **物理反馈是特色**（演示里风扇能手动转起来）。
7. 灵感来自《艺术创想》(Art Attack)。
8. 立意：AI 时代「**人人都是艺术家**」——
   > 这句话里的"人"，永远是那个充满想象力、独特、而不可替代的。

## 截图里读出的界面事实

| 位置 | 内容 |
|---|---|
| 左栏（上） | 玩家列表：头像 + 名字 + 猜出的词 |
| 左栏（下） | 素材库：网格缩略图，每件带**同款数量徽章**（3/1/0/2） |
| 中右 | **画布：一整块高饱和橙色**，占全屏约 65% |
| 画布右上 | **答案大字**（「马」，棕底）+ 全选 / 清空 |
| 画布左上外 | 「回合 1/1」日历小签 |
| 选中物件 | 黄色角点选框 + 旋转把手 + **竖排工具条**（上移/下移/翻转/删除） |

素材库页（02）里还有：分类货架（过时玩具 / 生锈金属 / 基础破烂）、
**形状配比统计**（4/3 3/3 3/3 …）、「所有数量 19」、「保存素材库」。

## 与我们项目的差异（值得想清楚的）

| | 破烂艺术家 | 我们 |
|---|---|---|
| 画布形状 | **横向大矩形**，填满中右 | **正方形**（aspect-ratio:1） |
| 画布底色 | **高饱和橙色** | 米白纸 + 8px 稿纸格 |
| 素材 | 写实 3D 渲染的实物，有锈迹肌理 | emoji |
| 界面语言 | 篝火 / 灯泡小人 / 手绘装饰 | **1管51 机构的单据与印章** |
| 答案位置 | 画布右上角 | 右栏交题单内 |

**最后一行不是缺陷** —— 单据/印章那套是我们自己的语言，参考游戏没有。
但**前两行是实打实的差距**：它的画布是「一块可以随便折腾的大桌面」，
我们的画布是「一张居中的稿纸」。
